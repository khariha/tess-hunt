# tess-hunt

An agent-driven transit search of TESS full-frame images for planets around faint red dwarfs.

Built and operated by Kishore Hariharan (Generative Experiences) with Claude, Anthropic's AI coding agent, in October 2026. The author had no prior background in exoplanet science. Everything here, including the mistakes, is in the commit history and in the Pitfalls section of `CLAUDE.md`.

## What it does

1. **Select targets** (`scripts/select_targets.py`): every TESS Input Catalog M dwarf in a sector with Tmag 12 to 15 and radius under 0.6 solar that is not a 2-minute target, TOI, Community Candidate, or known planet host. Sector 1: 40,328 stars.
2. **Sweep** (`scripts/modal_sweep.py`): for each star, cut a 15x15 pixel stamp from the public SPOC FFI sector cubes on AWS (astrocut), build a light curve, regress out shared systematics, flatten, mask pointing jitter, run a box least squares search, and apply a transit-shape candidate bar. Runs on Modal, about 8 CPU-seconds per star.
3. **Vet** (`scripts/vet_candidates.py`): catalog cross-match, Gaia DR3 neighbors with dilution math, centroid shift, and a noise-normalized difference image that locates the dip. One report per candidate.
4. **Follow up** (`scripts/followup.py`): recover the signal independently in every sector TESS observed the star, then stitch and refine.
5. **Fit** (`scripts/oddeven_fit.py`, `scripts/mcmc_fit.py`): physical transit model (batman + emcee) with free limb darkening; odd/even and secondary tests.
6. **Package** (`scripts/make_ctoi_package.py`): the report and values for an ExoFOP Community Candidate submission.

`tesshunt/pipeline.py` holds the five moves (clean, flatten, search, fold, vet) plus the pixel-to-light-curve and centroid code; `tesshunt/sweep_core.py` runs one star end to end; `tesshunt/transitfit.py` is the fitting layer.

## Results so far

Sector 1: 38,620 stars searched, 22 flagged, 3 candidates that pass every test and repeat in every available sector:

| TIC | Period (d) | Depth | Radius | Sectors |
|---|---|---|---|---|
| 389723320 | 3.927167 | 1.3% | 4.6 Earth | 6 |
| 114949540 | 2.739176 | 0.9% | 4.35 Earth | 3 |
| 259719966 | 11.077205 | 3.8% | 0.94 Jupiter | 9 |

Reports and figures: `plots/candidates/submission/`. Write-up: `docs/rnaas/` (Research Note of the AAS, submitted). A fourth, grazing candidate (TIC 235013874) is held back.

## Reproducing

```bash
pip install lightkurve astrocut astroquery tess-point batman-package emcee modal
python scripts/select_targets.py --sector 1          # ~25 min of catalog queries
modal run --detach scripts/modal_sweep.py --sector 1 # ~3 h on 50 CPU containers
modal run scripts/modal_sweep.py --sector 1 --mode pull
python scripts/vet_candidates.py --sector 1
python scripts/followup.py --sector 1 --tic <TIC>
python scripts/mcmc_fit.py --sector 1 --tic <TIC> --period <P>
python scripts/make_ctoi_package.py --sector 1 --tic <TIC>
```

Data and plots are not tracked; `data/` and most of `plots/` are regenerated by the scripts.
